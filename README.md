# Call Of Duty Modern Warfare — ระบบเรียกปฏิบัติหน้าที่

ระบบเรียกผู้ใต้บังคับบัญชาแบบเรียลไทม์ ใช้งานผ่านเว็บ/มือถือ และติดตั้งเป็นแอปบนหน้าจอโฮมได้ เก็บข้อมูลไว้ใน **Google Sheet**

| ส่วน | การเข้าใช้ | ความสามารถ |
|---|---|---|
| **COMMANDER** (ผู้บังคับบัญชา) | ชื่อผู้ใช้ `commander` · รหัส `9999` | เลือกประเภทการเรียก (เหตุฉุกเฉิน, ประชุมด่วน, เตรียมพร้อม, รวมพล, ติดต่อกลับ หรือพิมพ์เอง) · เลือกผู้รับ (ทุกคน/รายทีม) · เห็นป๊อปอัปทันทีเมื่อมีคนตอบรับ · ดูรายชื่อผู้ที่ตอบรับแล้วและผู้ที่ยังไม่ตอบรับ · ทะเบียนกำลังพลพร้อมสถานะออนไลน์ · ประวัติการเรียก |
| **STAFF** (ผู้ใต้บังคับบัญชา) | ลงทะเบียนครั้งแรก: ชื่อจริง, นามสกุล, ชื่อเล่น, ทีม, ไอดีไลน์ (บังคับทุกช่อง) | เมื่อถูกเรียก จะขึ้นหน้าจอแจ้งเตือนเต็มจอ เสียงไซเรนดังวน + สั่นต่อเนื่อง **จนกว่าจะกด “รับทราบ / ตอบรับ”** แล้วชื่อจะส่งไปที่จอผู้บังคับบัญชาทันที |

## จดจำรหัส & อัปเดตอัตโนมัติ

- **ผู้บังคับบัญชา:** ติ๊ก “จดจำรหัสในเครื่องนี้” (ติ๊กไว้ให้แล้ว) เข้าครั้งแรกครั้งเดียว ครั้งต่อไปเปิดลิงก์แล้วเข้าได้ทันที ถ้ากดออกจากระบบ รหัสยังกรอกไว้ให้ ถ้าไม่ติ๊ก ระบบจำไว้แค่จนปิดแท็บ
- **ผู้ใต้บังคับบัญชา:** ลงทะเบียนครั้งแรกครั้งเดียว ระบบจำข้อมูลไว้ในเครื่อง
- **บังคับอัปเดต:** แอปตรวจ `version.json` ทุก 1 นาทีและทุกครั้งที่เปิดกลับมา เจอเวอร์ชันใหม่ → **รีเฟรชทันทีทุกเครื่อง** (service worker ตัวใหม่ยังสั่งโหลดหน้าเวอร์ชันเก่าที่เปิดค้างอยู่ใหม่ให้ด้วย)
  - ระหว่างเสียงเตือนดังจะไม่รีเฟรช จะรอจนกดตอบรับก่อน
  - หลังรีเฟรช ผู้ใต้บังคับบัญชาแตะ “เริ่ม” อีกครั้งเพื่อเปิดเสียงในแอป (ระหว่างนั้นยังได้รับแจ้งเตือนแบบ push ตามปกติ)
- **เมื่อแก้ไขโค้ด:** รัน `bash tools/bump-version.sh` ก่อน commit เพื่อให้ทุกเครื่องรีเฟรชเป็นเวอร์ชันใหม่

## เชื่อมต่อ Google Sheet (ทำครั้งเดียว ~5 นาที)

ถ้ายังไม่ได้ตั้งค่า ระบบจะทำงานใน **โหมดทดลอง** (ข้อมูลอยู่ในเครื่องนั้นเท่านั้น ใช้ทดสอบโดยเปิดสองแท็บในเบราว์เซอร์เดียวกัน)

1. สร้าง Google Sheet ใหม่ที่ https://sheets.new
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) → กด 💾 บันทึก
4. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → กด **Run** → อนุญาตสิทธิ์ (Advanced → Go to … (unsafe) → Allow)
   ระบบจะสร้างแท็บ `Staff`, `Calls`, `Responses`, `Push` ให้อัตโนมัติ
5. กด **Deploy → New deployment** → รูปเฟือง ⚙ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   → กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. นำ URL ไปใส่ในไฟล์ [`config.js`](config.js) ที่ `API_URL: ''` (แก้บน GitHub ได้เลย กดรูปดินสอ → Commit)

   หรือไม่ต้องแก้ไฟล์ก็ได้ — ส่งลิงก์แบบนี้ให้ทุกคนเปิดครั้งแรก ระบบจะจำไว้ในเครื่อง:
   `https://boss5104.github.io/call-of-duty/?api=URL_ที่คัดลอกมา`

เมื่อเชื่อมต่อสำเร็จ มุมขวาบนจะแสดง **● ออนไลน์** แทน “โหมดทดลอง”

> เปลี่ยนรหัสผู้บังคับบัญชาได้ที่ `COMMANDER_PIN` ใน `Code.gs` และ `'9999'` ใน `assets/app.js` (ต้องตรงกัน) แล้ว Deploy → Manage deployments → Edit → New version

- เปิดลิงก์จาก **LINE** ระบบจะเด้งไปเปิดในเบราว์เซอร์หลักให้อัตโนมัติ เพื่อให้ติดตั้งและเสียงเตือนทำงานได้

## เสียงเตือน

- **เลือกเสียงได้ 10 แบบ** (ผู้บังคับบัญชาเลือกตอนส่งการเรียก แตะเพื่อฟังตัวอย่าง — ผู้รับทุกคนจะได้ยินเสียงนั้น): Hell March 2, ปลุกตายยาก, ไซเรนภัยทางอากาศ, ไซเรนรถฉุกเฉิน, แตรสถานีรบ, สัญญาณไฟไหม้, นาฬิกาปลุกดิจิทัล, กระดิ่งนาฬิกาปลุก, แตรเรียกพล, มาร์ชทหาร
- ระบบขยายเสียงเต็มที่ (บูสต์ + ลิมิตเตอร์ จนสุดเพดานที่เบราว์เซอร์ส่งออกได้) ปรับระดับได้ที่ `ALARM_BOOST` ใน `config.js` (1–6)
- **ใช้เพลงของคุณเอง:** อัปโหลดไฟล์เสียงชื่อ `alarm.mp3` ไว้ในโฟลเดอร์ `assets/`
  (บน GitHub: เปิดโฟลเดอร์ `assets` → **Add file → Upload files** → ลากไฟล์ → **Commit changes**)
  ระบบจะเล่นไฟล์นั้นวนซ้ำจนกว่าจะกดตอบรับ ถ้าไม่มีไฟล์ ระบบจะใช้เสียงมาร์ชทหาร + ไซเรนสังเคราะห์ในตัว
- หมายเหตุ: repo นี้เป็นสาธารณะ ไฟล์ที่อัปโหลดจะดาวน์โหลดได้โดยทุกคน ควรใช้ไฟล์ที่คุณมีสิทธิ์เผยแพร่
- เว็บไม่สามารถเพิ่มระดับเสียงของโทรศัพท์เองได้ ผู้ใช้ต้องเปิดเสียงเครื่องให้สุดด้วย

## แจ้งเตือนเด้งขึ้นจอแม้ปิดแอป (Push) — ดังซ้ำจนกว่าจะตอบรับ

เมื่อผู้บังคับบัญชาส่งการเรียก เซิร์ฟเวอร์ (Apps Script) จะส่ง **Web Push** ไปทุกเครื่องทันที แม้ผู้ใต้บังคับบัญชาจะ **ปิดแอป ล็อกหน้าจอ หรือไม่ได้เปิดหน้าเว็บค้างไว้**

- แจ้งเตือน **เด้งขึ้นบนหน้าจอ** และ **ค้างอยู่จนกว่าจะกด** (มีปุ่ม **✅ รับทราบ / ตอบรับ** กดได้จากแจ้งเตือนเลย และปุ่ม **🔊 เปิดแอป** เพื่อเปิดจอเตือนเต็มจอพร้อมไซเรน)
- ข้อมูลการเรียกถูกเข้ารหัสส่งไปพร้อมแจ้งเตือน (มาตรฐาน RFC 8291) เครื่องปลายทางแสดงได้ทันทีไม่ต้องรอเซิร์ฟเวอร์
- **ส่งซ้ำทุก 20 วินาที** (ดัง + สั่นใหม่ทุกครั้ง) ไปเฉพาะคนที่ยังไม่ตอบรับ นานสุด 30 นาที — หยุดเองเมื่อทุกคนตอบรับหรือผู้บังคับบัญชาปิดการเรียก
- **ปัดแจ้งเตือนทิ้ง → เด้งกลับมาใหม่ทันที** จนกว่าจะกดตอบรับ
- เครื่องที่ **ไม่มีอินเทอร์เน็ต** ตอนถูกเรียก จะได้รับแจ้งเตือนทันทีที่กลับมาออนไลน์ (บริการ push เก็บไว้ให้ 30 นาที)
- ปรับค่าได้ที่ต้นไฟล์ `Code.gs`: `REPUSH_EVERY_SEC`, `REMIND_FOR_MIN`, `PUSH_TTL_SEC`

**อัปเดต Apps Script (ทำครั้งเดียว — จำเป็นสำหรับฟีเจอร์นี้):**
1. เปิด Apps Script ของชีต → วางโค้ดใหม่ทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs) → 💾 บันทึก
2. เลือกฟังก์ชัน **`setup`** → **Run** → อนุญาตสิทธิ์ใหม่ (ระบบขอสิทธิ์ “เชื่อมต่อบริการภายนอก” และ “ตั้งเวลาทำงาน” เพื่อส่ง push ซ้ำ) — จะได้แท็บ `Push` เพิ่มมา
3. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** (URL เดิม ไม่ต้องแก้ `config.js`)

**ลงทะเบียนใหม่ (บังคับ):** ตอนกด “ลงทะเบียน” ระบบจะขออนุญาตการแจ้งเตือนและสมัครรับ push ทันที — ถ้าไม่อนุญาต ลงทะเบียนไม่ได้ (เซิร์ฟเวอร์ตรวจซ้ำด้วย ปิดได้ที่ `REQUIRE_PUSH` ใน `Code.gs`) · iPhone ต้องเพิ่มแอปลงหน้าจอโฮมก่อน

**ผู้บังคับบัญชา:** กด **“ลบ / ให้ลงทะเบียนใหม่”** ในทะเบียนกำลังพล สำหรับคนที่ยังเป็น 🔕 — เมื่อเขาเปิดแอปครั้งถัดไปจะต้องลงทะเบียนใหม่ (และต้องอนุญาตการแจ้งเตือน) · หมายเหตุ: สิทธิ์การแจ้งเตือนเป็นของแต่ละเครื่อง ผู้บังคับบัญชาเปิดแทนจากระยะไกลไม่ได้

**ฝั่งผู้ใต้บังคับบัญชา (บังคับ):** ถ้ายังไม่อนุญาตการแจ้งเตือน แอปจะขึ้นหน้าบล็อก “เปิดรับแจ้งเตือนก่อนเข้าเวร” พร้อมวิธีแก้ (ถูกปิดกั้น / iPhone ต้องเพิ่มลงหน้าจอโฮม / เบราว์เซอร์ไม่รองรับ) เข้าเวรไม่ได้จนกว่าจะเปิด · ผู้บังคับบัญชาเห็นสถานะ 🔔/🔕 ของทุกคน

ขั้นตอน: เปิดแอป → แตะ “เริ่ม” → อนุญาตการแจ้งเตือน → ช่อง **“แจ้งเตือนเด้งขึ้นจอแม้ปิดแอป”** ต้องเป็นสีเขียว → กด **“ทดสอบแจ้งเตือนตอนปิดแอป”** แล้วปิดแอป/ล็อกจอภายใน 10 วินาที

## ปุ่มรีเฟรช & ลบการเรียกเก่า
- **⟳ รีเฟรช** (มุมขวาบน ทุกหน้า): ล้างแคช + อัปเดตเป็นเวอร์ชันล่าสุด + ลบแจ้งเตือนเก่าในถาดแจ้งเตือน แล้วโหลดใหม่
- **ปิดการเรียกทั้งหมด** (ใต้สถานะการตอบรับ เมื่อมีมากกว่า 1 รายการ): หยุดแจ้งเตือนทุกเครื่อง
- **ลบประวัติการเรียกเก่าทั้งหมด** (ใต้ประวัติการเรียก): ลบการเรียกที่ปิดแล้ว + รายชื่อผู้ตอบรับของการเรียกนั้นออกจาก Google Sheet
- เครื่องผู้ใต้บังคับบัญชาจะลบแจ้งเตือนของการเรียกที่ปิดแล้ว/ตอบรับแล้วออกจากถาดแจ้งเตือนเองอัตโนมัติ

## ลบรายชื่อ (ผู้บังคับบัญชา)
- **ลบ / ให้ลงทะเบียนใหม่** ข้างชื่อแต่ละคน หรือ **ลบรายชื่อทุกคน** ใต้ทะเบียนกำลังพล
- คนที่ถูกลบ เมื่อเปิดแอปครั้งถัดไปจะต้องลงทะเบียนใหม่ (ต้องอนุญาตการแจ้งเตือน) · ประวัติการเรียก/การตอบรับยังอยู่

### ทำให้ดังที่สุด

เว็บแอปเปลี่ยนเสียงของแจ้งเตือนระบบหรือข้ามโหมดเงียบเองไม่ได้ (ข้อจำกัดของ Android/iOS) แต่ **ตั้งในเครื่องได้ครั้งเดียว** (มีขั้นตอนในแอป หัวข้อ “📢 ตั้งค่าให้แจ้งเตือนดังสุด”):
- **Android:** ข้อมูลแอป → การแจ้งเตือน → ตั้ง **เสียง** เป็นเสียงที่ดังที่สุด (เสียงนาฬิกาปลุก/ไซเรน) · เปิด **ป๊อปอัปบนหน้าจอ**, **หน้าจอล็อก**, **ข้ามโหมดห้ามรบกวน** · แบตเตอรี่ → **ไม่จำกัด**
- **iPhone (iOS 16.4+):** ต้องเพิ่มลงหน้าจอโฮมก่อน · ตั้งค่า → การแจ้งเตือน → Call Of Duty → เปิดเสียง + แบนเนอร์แบบ **คงอยู่ (Persistent)** · iPhone ไม่รองรับการสั่นผ่านเว็บ
- เมื่อแตะแจ้งเตือนเข้าแอป จะขึ้นจอเตือนเต็มจอ + ไซเรนบูสต์เสียงสุด (`ALARM_BOOST`) วนจนกว่าจะกดตอบรับ

> ข้อจำกัดของเว็บ: ไม่สามารถ “เปิดจอเต็มทับหน้าจอล็อก” หรือ “ดังผ่านช่องเสียงนาฬิกาปลุกแม้ปิดเสียงเครื่อง” ได้ — ถ้าต้องการระดับนั้นต้องทำเป็นแอป Android แบบเนทีฟ

### โควตา Apps Script
ตัวส่งซ้ำทำงานเป็น trigger ทุก 1 นาที **เฉพาะตอนมีการเรียกค้างตอบรับ** แล้วลบตัวเองเมื่อทุกคนตอบรับ บัญชี Gmail ทั่วไปมีโควตา trigger รวม ~90 นาที/วัน (ประมาณ 1 นาทีต่อการเรียกที่ค้างนาน 1 นาที)

## ข้อควรรู้เรื่องการแจ้งเตือน

- เปิดแอปค้างไว้ยังให้ผลดีที่สุด (ไซเรนเต็มจอทันที ระบบกันหน้าจอดับให้อัตโนมัติ) แต่ไม่จำเป็นอีกแล้วเพราะมี push
- ระบบตรวจสอบคำสั่งใหม่ทุก ~4 วินาทีขณะเปิดแอป (ปรับได้ใน `config.js`)

## ไฟล์

```
index.html            หน้าเว็บหลัก (Commander + Staff)
assets/app.css        ดีไซน์
assets/app.js         การทำงานทั้งหมด
config.js             ตั้งค่า API_URL / รายชื่อทีม
sw.js                 Service worker (ติดตั้งเป็นแอป + รับ push + แจ้งเตือนค้างจนตอบรับ)
manifest.webmanifest  ข้อมูลแอปสำหรับหน้าจอโฮม
icons/                ไอคอนแอป
apps-script/Code.gs   Backend สำหรับ Google Sheet
```
