📢 ตั้งค่าให้แจ้งเตือนดังสุด + เด้งขึ้นจอ (ทำครั้งเดียว)

Android (ติดตั้งแอปลงหน้าจอโฮมแล้ว)

  1. กดค้างที่ไอคอนแอป Call Of Duty → ข้อมูลแอป (ⓘ) → การแจ้งเตือน → เปิดทุกช่อง
  2. แตะหมวดการแจ้งเตือน → เสียง → เลือกเสียงที่ดังที่สุด (เช่น เสียงนาฬิกาปลุก/ไซเรน)
  3. เปิด แสดงป๊อปอัปบนหน้าจอ · แสดงบนหน้าจอล็อก · ข้ามโหมดห้ามรบกวน
  4. ตั้งค่า → แบตเตอรี่ → แอป Call Of Duty / Chrome → ไม่จำกัด (ไม่ให้ระบบปิดแอปเพื่อประหยัดแบต)
  5. ปรับ เสียงแจ้งเตือน ของเครื่องให้สุด

ถ้าเปิดผ่าน Chrome (ไม่ได้ติดตั้ง): Chrome → ⋮ → การตั้งค่า → การแจ้งเตือน → เลือกเว็บนี้ → ตั้งเสียง/ป๊อปอัปแบบเดียวกัน

iPhone (ต้องเพิ่มลงหน้าจอโฮมก่อน iOS 16.4+ แล้วเปิดแอปจากไอคอน)

  1. ปิดโหมดเงียบ (สวิตช์/ปุ่ม Action ข้างเครื่อง — ถ้ามีรูปกระดิ่งขีดฆ่า 🔕 บนแถบด้านบน แจ้งเตือนจะไม่มีเสียง)
  2. ตั้งค่า → การแจ้งเตือน → Call Of Duty → เปิด อนุญาตการแจ้งเตือน, เสียง, หน้าจอล็อก/ศูนย์การแจ้งเตือน/แบนเนอร์ · รูปแบบแบนเนอร์: คงอยู่ (Persistent)
  3. ตั้งค่า → การแจ้งเตือน → แสดงตัวอย่าง: ทุกครั้ง (Always) — ถ้าไม่ตั้ง หน้าจอล็อกจะขึ้นแค่คำว่า “Notification”
  4. ตั้งค่า → เสียงและการสั่น → ลาก เสียงเรียกเข้าและเสียงเตือน ให้สุด · เปิด การสั่น: เล่นเสมอ
  5. ถ้าใช้โหมดโฟกัส/ห้ามรบกวน: เพิ่ม Call Of Duty ในแอปที่อนุญาต

iPhone ไม่อนุญาตให้แอปใด ๆ (ยกเว้นสายโทรเข้า/นาฬิกาปลุก) ขึ้นเต็มจอเมื่อล็อกอยู่ — แตะแจ้งเตือนเพื่อเปิดจอเตือนเต็มจอพร้อมไซเรน
